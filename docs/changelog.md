# 変更履歴

## 2026-11-07 要望メモのまとめてコピー

- 要望メモの画面に「全部まとめてコピー」を追加。番号付きの文章（未完了が先、完了は［完了］付き）でコピーし、チャットに貼って改修を頼めるようにした。自動でコピーできない端末では、選択用の文字欄を表示する

## 2026-11-01 カテゴリ追加とレポートの絞り込み

- 支出の追加画面のカテゴリ一覧に「＋追加」を追加。その場でカテゴリを作って選べる
- レポートでカテゴリを押すと集計から外せるようにした（端末ごとに保存）。初期費用など一時的な支出を除いて見るため
- 買い物リストの「買ったもの」を今月・先月に限定し、それより前は1か月ずつボタンで読み込む

## 2026-11-01 読み込み量の削減と買い物リスト

- 起動時に読む支出を「今月・先月」と「未精算」に限定。それより前の月は、履歴・レポートのボタンで読み込む
- 買い物リスト（5つ目のタブ）を追加。カテゴリは支出と共通。購入日の記録、「そろそろ買う時期」、「よく買うもの」、今日買ったものを支出に記録するボタン
- バックアップと全削除は、押したときに全件を読み込むように変更
- Firestoreのルールに `shopping` と `shopStats` を追加
- 予定の共有（Yahoo!カレンダーとGoogleカレンダーの統合）は検討のみ。Yahoo!カレンダーに外部から読める仕組みがないため見送り

## 2026-10-23 名前を「ペアマネ」に変更

- アプリ名を「おあいこ」から「ペアマネ」（ペアのマネー管理）に変更
- ロゴとアイコンを「にっこりコイン」（青とピンクのコインが寄り添って笑い、上にハート）に変更。起動画面とホームの見出しにロゴを表示
- 起動画面の下に空のタブバーが出ていた不具合を修正
- 精算完了の全画面表示を「精算完了」に変更
- リポジトリ名を `oaiko` から `pairmane` に変更。URLは https://nehaokn.github.io/pairmane/ 。端末の保存キーも `pairmane.*` に変更し、ふたりの接続を最初からやり直した
- LINEなどアプリ外のブラウザで始めたときの注意表示を追加
- 匿名ログインを、作成・参加のボタンを押したときまで遅らせた。ページを開くたびに匿名アカウントが増えていた（1日で22件）ため
